# HH_DB

Программа, получающая данные о компаниях и вакансиях с сайта [hh.ru](https://hh.ru), загружает полученные данные в спроектированные таблицы в БД PostgreSQL.

Статус: в разработке

## <a id="title1">Установка</a>

1. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:olgapythonwq/HH_DB.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd ваш_проект
   ```
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
